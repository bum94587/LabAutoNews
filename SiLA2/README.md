# SiLA 2 virtual drivers for a Hamilton STAR digital twin (POC)

A scheduler runs a time-compressed **microsomal-stability workflow** through two **SiLA 2 servers**
("virtual drivers"): one wraps a **Hamilton STAR digital twin** built on PyLabRobot's firmware-level
STAR simulator, the other a **heater-shaker twin** with a simple thermal model. Everything runs on
Linux with open-source tools and no hardware.

- **Read the documentation:** [`docs/index.html`](docs/index.html), also published as a private page at
  https://claude.ai/artifact/U8ouQ7rr4PBSG5wbWG5TXo (architecture, results, step-by-step
  instructions, proposal for a real lab) and the deep dive on the SiLA 2 driver landscape,
  [`docs/sila2-drivers-deep-dive.md`](docs/sila2-drivers-deep-dive.md).
- **Last run** ([`results/run_summary.md`](results/run_summary.md)): 27/27 steps succeeded in 32 s real
  time, 863 Hamilton firmware commands sent to the simulated STAR, final volumes exactly as expected.

## Quick start

Needs Linux or macOS (WSL works), git, and [uv](https://docs.astral.sh/uv/).

```bash
cd SiLA2
uv sync                         # Python 3.12, sila2 0.14.0, PyLabRobot @ 7779f50, both server packages
uv run python run_demo.py       # starts both SiLA 2 servers, runs scheduler/workflow.yaml, writes results/
```

Tests: `uv run python tests/test_hhs_twin.py`, `uv run python tests/test_lh_twin.py`,
`uv run python tests/test_smoke.py`.

## Layout

| Path | What it is |
|---|---|
| `features/*.sila.xml` | SiLA 2 feature definitions (LiquidHandlerService, HeaterShakerService), generated by `features/make_fdl.py` |
| `servers/lh_twin/` | SiLA 2 server for the STAR twin (`feature_implementations/twin.py` = PyLabRobot side, `liquidhandlerservice_impl.py` = SiLA adapter) |
| `servers/hhs_twin/` | SiLA 2 server for the heater-shaker twin (`thermal.py` = model) |
| `scheduler/` | Workflow file, scheduler (one lane per device, dependencies, timed steps, watchdog), report/plots |
| `run_demo.py` | One command: start servers, run, collect results, stop servers |
| `results/` | Output of the last run: timeline, firmware trace, well volumes, Gantt chart, plate heat maps, summary |
| `PLAN.md`, `REVIEW.md` | The build contract and the independent reviewer's findings (all should-fix items addressed) |

Built 3 Nov 2026 by Claude with parallel builder agents and an independent reviewer agent. POC only:
simulated hardware, localhost, unencrypted SiLA (`--insecure`), not for production use.
