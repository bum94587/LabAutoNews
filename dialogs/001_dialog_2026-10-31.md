## Answer

Built it to mirror money_systems (uv, Python 3.12, top-level `uv run <script>.py` tools, briefs in
`docs/news/` on `claude/*` branches, pulled into myday by `tools/pull_news.py`).

**Decisions**
- **Daily research, weekly brief.** One scheduled task (daily 04:47 America/Los_Angeles, fresh
  session). Every day it writes structured items to `data/items/D.jsonl`; on Mondays it also
  renders `docs/news/D_lab-automation-weekly.md`.
- **Structured items, rendered brief.** Claude writes JSONL items (summary, claims each tied to a
  numbered ref, analysis kept separate, segment/type/source/how-found/query, a 1-5 relevance guess);
  `build_brief.py` renders the markdown so every story reliably has its id, badges, sources and a
  rating line. `validate.py` enforces "no link, no claim" and the schema.
- **Verifier agent always runs** (`.claude/agents/verifier.md`): separate context, checks facts
  (who/what/when/numbers; funding/M&A need a primary or two independent sources) and
  science/engineering soundness (plausibility, evidence level, baselines, real closed loop for
  "autonomous", regulatory status). Writes verdicts to `data/verify/D.jsonl` with the URLs it
  checked and corrections; contradicted items are listed, not silently dropped.
- **Rating where you read.** Each story ends with `> **Rate:** _/5 · **Tags:** _ · \`id\``, edited in
  the myday viewer; the brief has a Brief/Missed/Notes line. `harvest_ratings.py` reads them back
  from myday, `learn_weights.py` learns shrunk per-feature effects (source, segment, type, method,
  domain, company, verdicts) into `config/weights.json` + `docs/tuning.md`, with calibration of
  the researcher's relevance guesses and of the verifier. Rebuilding a brief keeps filled-in ratings.
- **State across branches.** Each cloud run pushes its own branch, so `sync_state.py` unions the
  append-only JSONL data from `origin/main` + all `origin/claude/*` at the start of every run.
- **Sources** in `config/sources.yaml`: SLAS, LRIG, ELRIG, Labautomation.io and the
  lab-automation sections of Hamilton, Tecan, Agilent, Beckman (include/exclude keyword filters),
  plus secondary trade press, wires and preprints. ("LRIG" taken as the Laboratory Robotics Interest
  Group; ELRIG added too.)
- **Network**: the cloud environment blocks direct fetches of all eight source domains, so
  `fetch_sources.py` logs failures and runs fall back to site-restricted WebSearch.
- **myday**: `tools/pull_news.py` generalised to several linked projects (money_systems,
  labautonews), a `projects/labautonews/` linked project (README, how-it-works, rating guide,
  sources), CLAUDE.md "update" section and how-tos updated; pushed to a myday branch for review.

First run done interactively as an October backfill: 11 items, verified, rendered as the first
brief `docs/news/2026-10-31_lab-automation-weekly.md`.

## Answer

- **PyLabRobot** added as a core source. GitHub's web/API is blocked from the cloud but git works,
  so `fetch_sources.py` gained a `git-log` fetch type (merged PRs + release tags, last 14 days) and
  sources can now have several fetch blocks (also its labautomation.io category). Runs report it
  as one weekly roll-up. The verifier checked the first roll-up against the git history and
  corrected three framings (PF400 driver already existed; most PRs were CLARIOstar work; STAR
  dispense checks were relaxed, not tightened).
- **Scope list in every brief**: a table of every site (tier, how checked, candidates, stories),
  every watched company with its story count, and companies in the news but not watched. A new
  `> **Scope:** Add: … · Remove: …` feedback line is harvested (`kind: "scope"`), applied to
  `config/` by the next run, logged in `data/feedback/scope_log.jsonl`, and shown as "Scope changes
  applied". Feedback is now harvested every run, not only Mondays.
- **Shorter brief**: stories are badge + headline + ≤2 sentences + one-line "Why" + up to 3 source
  links; numbers, verifier notes and full source lists moved to a Details section at the end.
  `validate.py` caps title/summary/why at 14/50/30 words; editorial at ≤4 TL;DR bullets.
- **Filtered out kept and expanded**: items left out (with a short reason) plus a new "Screened
  out during research" list from each run's `rejected` candidates.
- First brief reissued in the new format.
